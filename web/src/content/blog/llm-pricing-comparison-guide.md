# LLM Pricing Comparison Guide

Choosing the right LLM provider can save you thousands of dollars per year. This guide compares pricing across major providers to help you find the best value.

## Pricing Models

### Pay-Per-Token
Most providers charge per million tokens:
- **Input tokens**: $0.15 - $15.00 per million
- **Output tokens**: $0.60 - $60.00 per million

### Subscription-Based
Some providers offer flat-rate subscriptions:
- **OpenCode Go**: $10/month for unlimited usage (with limits)
- **Anthropic Claude Pro**: $20/month for priority access
- **ChatGPT Plus**: $20/month for GPT-4 access

### Free Tiers
Many providers offer free tiers with limits:
- **HuggingFace Router**: Free for open-source models
- **Groq**: Free tier with rate limits
- **Together AI**: Free credits for new users

## Cost Optimization Tips

### 1. Use Free Tiers First
Start with free tiers to prototype and test. Most providers offer enough free credits for development.

### 2. Batch Processing
Use batch processing endpoints for non-urgent tasks. Many providers offer 50% discounts for batch jobs.

### 3. Off-Peak Usage
Some providers offer lower prices during off-peak hours (typically 2-6 AM UTC).

### 4. Cache Prompt Tokens
Use providers that support prompt caching to avoid re-processing the same context.

### 5. Choose the Right Model
Don't use GPT-4 for simple tasks. Use smaller models like GPT-3.5 or Llama 3.1 for basic operations.
